Pokemon illustrations (001–151): PokeAPI sprites repository, official-artwork directory.
Source: https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork
Pokemon and character artwork belong to their respective owners (Nintendo / Creatures / GAME FREAK).

kanto-profile-frame.png: generated with the built-in image generation tool for this project.
Prompt: Empty futuristic RPG trainer profile banner, transparent exterior, large circular portrait socket and overlapping level medallion, layered angular luminous orange/gold frame, dark interior, flame details, no text, no characters. Live labels and Pokemon illustrations are composed separately by Unity.

All 151 themes share this illustrated frame. The game changes its palette and the species illustration with the trainer's level; these are not 151 separately painted frames.
